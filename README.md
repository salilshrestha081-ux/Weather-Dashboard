# Weather Dashboard

A responsive weather dashboard built using React and Vite.

## Features

- Search weather by city
- Current weather information
- 5-day weather forecast
- Celsius and Fahrenheit temperature units
- Search history
- Clear search history
- Use current location
- Responsive design

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Open-Meteo API
